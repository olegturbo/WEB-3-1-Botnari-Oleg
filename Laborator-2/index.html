Partea 1 – Republica Moldova

Republica Moldova este un stat din Europa de Est, situat între România și Ucraina. Capitala este Chișinău, iar țara este cunoscută pentru podgorii, mănăstiri și peisaje de deal.

Partea 2 – Norvegia

Norvegia este o țară nordică, cunoscută pentru fiorduri, munți și aurora boreală. Capitala este Oslo, iar turismul în natură este una dintre principalele atracții ale țării.

  4. Plimbare cu trenul pe linia Flåm

Partea 3 – Suedia

Suedia este cea mai mare țară din Scandinavia, cu păduri întinse, mii de lacuri și un arhipelag bogat. Capitala este Stockholm, iar țara este renumită pentru design și inovație.
